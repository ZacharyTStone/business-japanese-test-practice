# What a line does:
#   - `bjt publish` writes `is_published = false` for the item into its bundle's

#     everybody. The row stays: answers already given keep resolving.

#     lint, so a committed item with a mechanical tell has to be named here.
#
# Deleting a line does not put an item back: the bundle SQL never sets
